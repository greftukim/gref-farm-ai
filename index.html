모델 구조 — 3단계 광합성 계산

TOMGRO 는 Lambert-Beer 빛 분포 → 잎 단위 광합성 (Farquhar 간소화) → 캐노피 전체 적분의 3단계 구조로 이론 건물 생산량을 계산함

Step 1: Lambert-Beer 법칙 (캐노피 층별 빛 감쇠) I(L) = I₀ · exp(−K_ext · L) K_ext = 0.7 (토마토 실측 평균, Heuvelink 1996) Step 2: 잎 단위 광합성 (직각쌍곡선) P_leaf = (α · PAR · P_max) / (α · PAR + P_max) α = 0.05 mol CO₂ / mol 광자 P_max = 25 μmol CO₂/m²/s (기준, CO₂ 350ppm · 25°C) Step 3: 캐노피 전체 (5개 층 적분) P_canopy = Σ P_leaf,i · ΔL_i 시간당 환산: × 3600 × 30 / 10⁶ = g CH₂O/m²/hr

LAI 계산 방법 (Heuvelink 1995)

TOMGRO 의 핵심 입력 변수 LAI 는 원본 PRIVA 데이터에 없으므로 주간 생육 측정값에서 계산함

LAI = (엽장 × 엽폭 × SHAPE) × 엽수 × 재식밀도 SHAPE = 0.5 (본 농장 기준 · 토마지노 품종 잎 형상 계수) 재식밀도 = 2.78 주/m² (본 농장 실측) 저온기 한겨울 실제 계산: L = 0.363 m, W = 0.300 m 잎 면적 = 0.363 × 0.300 × 0.5 = 0.0545 m² 주당 엽면적 = 0.0545 × 20.0 = 1.089 m² LAI = 1.089 × 2.78 = 3.027 m²/m²
SHAPE 계수 0.5 선택 근거
Heuvelink (1995) 논문은 일반 대형 토마토 기준으로 0.7 을 제시하나, 본 농장 토마지노 품종 (방울토마토 계열) 은 잎 형상이 다름 재배사 실측 결과 잎 크기 대비 실제 엽면적 비율이 0.4~0.5 수준으로 확인됨 따라서 본 프로젝트는 SHAPE = 0.5 를 사용함 (방울토마토 실측 근거)

모델 구조 — 선형 EC 손실 수식

Maas & Hoffman (1977) 의 고전 선형 모델을 방울토마토에 맞춰 적용. 슬라브 EC 가 임계값을 넘으면 초과량에 비례해 수량이 선형적으로 감소함

Y_r = 1 − b · (EC_slab − EC_threshold) 파라미터 (방울토마토 기준): EC_threshold = 2.5 dS/m (임계 EC) b = 0.045 /dS/m (손실 계수, 초과 EC 1 dS/m 당 4.5% 감소) 저온기 한겨울 계산: EC_slab = 5.56 dS/m Y_r = 1 − 0.045 × (5.56 − 2.5) = 1 − 0.045 × 3.06 = 1 − 0.138 = 0.862 ≈ 0.860 (평균값 기준)

세 가지 EC 중 슬라브 EC 선택 이유

본 농장에는 EC 측정 지점이 3곳 있으나, 식물이 실제 흡수하는 근권 EC 를 사용함

왜 공급 → 슬라브 → 배액 순으로 EC 가 증가하는가?
온실 재배에서 식물은 물만 선택적으로 흡수하고 염류는 남기므로, 공급 → 슬라브 → 배액 순서로 EC 가 농축됨 본 농장의 2.84 → 5.56 → 6.83 dS/m 패턴은 정상 관수·배액 시스템의 전형적 모습임

DeePC 기본 개념

DeePC 의 핵심 개념. 과거 궤적 데이터에서 Hankel matrix 를 구성하여 미래 행동을 예측. 시스템 모델링 없이 데이터만으로 최적 제어 가능 (Willems' Fundamental Lemma).

제어 전략 종합 (v7 vs v8 vs 실제)

96시간 제어 전략 비교 요약표. 온도·CO₂·제어·스크린·성과 카테고리별로 v7 · v8 · 실제 운영 비교. v8 밴드 준수율 100% vs 실제 14%, 난방 편차 v8 1.3°C vs 실제 23.8°C 등 제어 특성 차이 명확.

v7 vs v8 vs 실제 시계열 비교

온도 · CO₂ · 난방 · 환기 4개 지표의 96시간 시계열. v8 은 참조 궤적에 가깝게 부드럽게 제어하며, 밴드 준수율 100% 달성. 실제 운영은 on/off 스윙이 심하고 밴드 이탈 빈번.

3중 스크린 제어 패턴

스크린 1·2·3 개도 비교. 실제 운영은 새벽 100% / 낮 0% 뚜렷한 시간 패턴. DeePC v8 은 약 10% 고정값으로만 제어. DeePC 근본 한계: 평균치 근처 최적화 특성상 시간대별 리듬을 학습 못 함

DeePC 근본 한계

DeePC 는 본질적으로 시간 패턴을 학습하지 못함
Hankel matrix 는 과거 궤적의 선형 조합으로 미래를 예측하는 특성상, "평균치 근처에서 최적 해를 찾는 경향"이 있음 실제 농부의 새벽↑ 낮↓ 스크린 리듬이나 난방 on/off 스윙 같은 시간 의존적 패턴은 재현 불가
왜 평균치 근처로 수렴하는가

① Hankel matrix 구조

Hankel matrix 는 과거 창(window) 을 슬라이딩 해서 만든 행렬

· 과거 데이터의 "조각들" 을 모아둔 거대한 데이터베이스

② 미래 예측 = 과거 조각들의 가중 평균

· 결과적으로 극단값들이 서로 상쇄되어 "평균치" 로 수렴
· 수학적으로는 "편차가 가장 작은 해" → 이게 최적화 목표

③ 실제 농부는 극단을 오가는 전략을 씀

· 새벽 100% ↔ 낮 0%, 난방 ON 70°C ↔ OFF 30°C
· DeePC 는 이 극단을 평균 50% 근처로 뭉갬
· "수학적 최적" vs "실무 최적" 의 괴리

APPENDIX · AGRICULTURAL WORK

농작업 영향 모델링

FarmWork 시스템 도입 대비 이론 + 간접 분석 + Phase 2 로드맵. 본 작기 실측 농작업 기록은 없으나, 생육 데이터로 간접 분석 수행.

엽수 변동으로 본 적엽 추적 (실측 데이터)
본 작기 실측 엽수·LAI 주간 변동. 엽수 ≥ 0.5매 감소 주 13회 추정 (빨간 음영) = 적엽 작업 추정 시점. LAI 도 동시 감소 확인 → 적엽이 TOMGRO 광합성 계산에 직접 영향.
적과 영향 시뮬레이션 (가상)
가상 적과 시나리오. 적과 20% 시 과실 수는 감소하지만 평균 과중 +30% 증가로 20주 누적 수확량 +4.0% 개선 가능성. 단, 실제 효과는 품종·시기·환경에 따라 다름 → Phase 2 실측 필요.
