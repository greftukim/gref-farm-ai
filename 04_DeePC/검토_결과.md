### P1-03: 섹션 7.3 AI 타깃 표 — RH 코드 vs 표 불일치 → **해결됨**

코드 (섹션 2.4):
```python
if radiation > 300: rh_opt = 68.0
elif radiation > 50: rh_opt = 72.0
else: rh_opt = 78.0
```

섹션 7.3 표에서 "일사 > 200 W/m²: RH 68%" 로 기재되어 있으나, 실제 코드는 radiation = 200~300 구간에서 RH = **72%** (elif radiation > 50 분기). 300 초과에서만 68%.

| radiation 범위 | 코드 RH | 표 RH |
|---|---|---|
| > 400 | 68% | 68% ✅ |
| > 300 (≤ 400) | 68% | 68% ✅ |
| > 200 (≤ 300) | **72%** | **68%** ❌ |
| > 150 (≤ 200) | 72% | 72% ✅ |

**처리**: 섹션 7.3 표에 각주 추가: "※ RH 임계치는 300 W/m² (코드 기준) — 온도 임계치 200/150 과 다름. 일사 200~300 구간 RH = 72%."

## 5. 수식 정합성 검증 ✅ 전체 이상 없음

| 수식 | 검증 결과 |
|---|---|
| Willems Lemma: $\begin{bmatrix} u_f \\ y_f \end{bmatrix} = \begin{bmatrix} U_p \\ Y_p \end{bmatrix} g$ | 표준 형식 ✅ |
| Hankel matrix (T=3, n=6): 3×4 행렬 | rows=T=3, cols=n-T+1=4 ✅ |
| DeePC 최적화: $\min \|y-y_{ref}\|^2 + \lambda_u\|u\|^2 + \lambda_g\|g\|^2 + \lambda_{smooth}\|\Delta u\|^2$ | 표준 DeePC ✅ |
| 환기 급변 제약: $\|u_{vent}(t+1)-u_{vent}(t)\| \le 5\%$ | 코드와 일치 ✅ |
| z-score 정규화: $u_{norm} = (u - \mu_u) / \sigma_u$ | 표준 ✅ |
