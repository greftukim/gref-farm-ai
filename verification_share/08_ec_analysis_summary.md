# EC 분석이 Phase 1.5를 이끌어낸 과정 — 발견 스토리

생성일: 2026-04-20

---

## Phase 1 완성 시점의 문제 인식

Phase 1 완성 당시 (SV_EC_LAG=7, WMAPE 25.2%):
- S&V EC 적용 후 WMAPE가 35.5%로 **오히려 악화**
- TOMGRO 단독(25.6%) 대비 S&V 적용 시 오히려 나빠지는 역설적 상황
- EC가 수확량 예측에 기여하는지 의문

두 가지 가설이 제기됨:
- **가설 A**: EC가 LAI를 통해 이미 TOMGRO에 반영됨 (이중 계산 우려)
- **가설 B**: S&V 시차 설정이 잘못됨 (수확 1주 전 EC가 최적이 아닐 수 있음)

---

## EC 심층 분석 (verification_share_v2)

### 가설 A 검증: EC-LAI 상관 분석

EC(t-k주)와 LAI(t)의 상관계수를 다양한 시차(0~8주)에서 분석:

| 시차 | r(EC→LAI) | 해석 |
|---|---|---|
| 0주 | -0.12 | 동시기 상관 없음 |
| 1주 | -0.08 | 미미 |
| 4주 | -0.21 | 약한 음의 상관 |
| 7주 | -0.31 | 중간 (임계값 -0.40 미달) |

**가설 A 기각**: EC가 LAI를 통해 TOMGRO에 이중 반영되는 유의한 증거 없음.
S&V EC 스트레스 항은 독립적으로 유효.

### 가설 B 검증: 최적 시차 탐색

각 시차에서 S&V 재적용 + XGBoost CV 재훈련 후 최종 WMAPE 측정:

| 시차 (수확 X주 전) | SV_EC_LAG (코드) | S&V WMAPE | 최종 WMAPE |
|---|---|---|---|
| 1주 (Phase 1 현재) | 7 | 35.0% | 24.5% |
| 3주 | 5 | 35.7% | 23.7% |
| 4주 ★ | 4 | 35.3% | 22.9% |
| 6주 | 2 | 34.8% | 22.3% |
| **7주 (최적)** | **1** | **34.0%** | **21.5%** |
| 8주 | 0 | 34.2% | 23.3% |

**임계값 검증 (사전 선언)**:
- 조건 1: 최적 시차 ≠ 1주 → **7주** ✓
- 조건 2: 최종 WMAPE 개선폭 vs 현행 ≥ 2.0%p → **3.7%p** ✓
- 조건 3: 최종 WMAPE 개선폭 vs TOMGRO(25.6%) ≥ 2.0%p → **4.1%p** ✓

**3×3 민감도 분석**: 9개 임계값 조합 모두 동일 결론 → **ROBUST**

→ **가설 B 성립**: 최적 시차 = 7주 (착과기, SV_EC_LAG=1)

## 생리학적 재해석

EC 반응 메커니즘 재정립:

```
착과 시점 (수확 7주 전)  → 세포 분열 단계 → 과실 크기 결정  ← 수확량(kg) 핵심
과실 비대기 (2~5주 전)  → 정해진 세포 수로 비대 진행
착색기 (1~2주 전)       → 당도·색상 집적, 크기 거의 불변   ← 당도(브릭스) 핵심
```

**재배사 피드백 재해석**:
- 박현도 재배사: "EC는 수확 직전(1~2주) 영향" → 당도 기준으로는 맞음
- Phase 1.5 정교화: **수확량(kg)은 착과기(7주 전) EC**, **당도는 수확 직전 EC**
