# Phase 2 로드맵

Phase 1 (WMAPE 25.2%) 달성 이후 개선 방향.

---

## 1. 데이터 수집 고도화

| 항목 | Phase 1 | Phase 2 목표 |
|---|---|---|
| 광량 | PRIVA 외부광 × 50% 추정 | 온실 내부 PAR 센서 직접 측정 |
| 엽면적 | 격주 수동 조사 (3주 평균) | 영상 기반 자동 LAI 추정 |
| EC | 슬라브 EC 일 1회 기록 | 배액 EC + 공급 EC 실시간 |
| 수확량 | 수기 입력 (당일 기록) | FarmWork 자동 연동 |

---

## 2. 모델 개선

### 2-1. TOMGRO 파라미터 튜닝
- 현재: epsilon=0.08, P_MAX=40 (캐노피 레벨 경험적 보정)
- Phase 2: 실측 광합성 곡선 기반 재보정
- 월별 온도 응답 (Q10) 검증

### 2-2. S&V 본 농장 튜닝
- 현재: Sonneveld & Voogt 표준 기울기 0.09, 임계 EC 2.5 dS/m
- Phase 2: 본 농장 EC-수확 회귀 데이터 충분 시 재보정
- 배액 EC 반영 (공급 EC 대신)

### 2-3. XGBoost 교체
- 현재: LinearRegression (데이터량 29주, overfitting 방지)
- Phase 2: 데이터 60주+ 확보 시 XGBoost 교체
- 시계열 특징 추가: 전주 수확량, 누적 적산온도, 재식 후 경과일

---

## 3. 시스템 연동

### FarmWork 연동
- 수확량 자동 수신 (API 또는 CSV Export)
- 급액 EC 데이터 자동 수신
- 주간 예측값 FarmWork 피드백

### 알림 시스템
- 예측 수확량 기반 수확 계획 자동 생성
- EC 임계치 초과 시 알림 (S&V 스트레스 5% 이상 시)

---

## 4. 성능 목표

| 지표 | Phase 1 | Phase 2 목표 |
|---|---|---|
| 전 작기 WMAPE | 25.2% | < 20% |
| 피크 시즌 (Oct-Jan) WMAPE | ~20% | < 15% |
| 초기 생육기 (Jul-Aug) WMAPE | ~30% | < 25% |
| 예측 리드타임 | 8주 전 | 8주 전 유지 + 4주 전 업데이트 |
